## Shared ownership/build (N-01, N-15, N-16)

Each implementation worker owns all source/build-manifest/test/resource assets within its OWN directory, including `Package.swift`, `Resources/**`, `Info.plist`, `tools/**`, README/FINDINGS and implementation report. Coordinator alone owns PLAN and independent review/progress files. Use dependency-free SwiftPM or a tools-owned swiftc harness, outputs under ignored .build/.tools. No host installs. Independent spec/quality review required for both. Findings are exact-prototype-specific; 004 evidence never validates 003 implicitly, and 003 has no stealth claim.

No progressive image pixel claim. Model/tool/skill/input/permissions/OMP status fields explicitly MOCK/NOT CONNECTED and tested.
