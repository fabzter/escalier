## Boundary statements

- No local result establishes HackerRank server-side invisibility; the page is synthetic and inert.
- Headless decision tests cannot distinguish an active tap from a listen-only tap. The static guard
  pins `.defaultTap` and the nil-return path, but only the runtime capability row can observe an
  enabled tap.
- The browser page cannot enforce that an OFF positive control was performed; the human run sheet
  makes a missing/zero control an INVALID case.
- Expected modifier delivery is a baseline, not a leak.
- IME, dead keys, composition, non-US layouts, secure input, browser accelerators, WindowServer
  chords and TCC identity behavior remain limitations; see README and implementation report.
