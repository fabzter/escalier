Recipient key and input oracle

Inert local page. No network, no storage, no timers beyond the precondition refresh, and no event suppression. Every listener is capture-phase and passive.

Focused editable test field

The page never reads or stores the field content. Counters count events, not characters.

Counters not reset in this load.

OFF positive control — required before any armed case

  1. Confirm Escalier capture is OFF and the tap has not been installed.
  2. Click the test field above and keep this tab active and visible.
  3. Send the same chord that the armed case will use, once, with the same browser profile and page.
  4. Send the known synthetic text from the run sheet, once.
  5. Record a non-zero selected-key count and a non-zero input count. Zero means INVALID, never PASS.
  6. Reset the counters, then arm capture while keeping this field focused.

The positive control must use the same chord, same profile, same page and the focused visible field.
